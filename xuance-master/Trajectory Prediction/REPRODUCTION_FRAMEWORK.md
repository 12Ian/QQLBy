# Yu 等（2026）机动目标轨迹预测复现：代码框架

论文 DOI：`10.1109/TAES.2026.3677846`。

## 1. 目标与边界

目标是复现论文 *Trajectory Prediction for Maneuverable Target Based on Intention Recognition and Intercept Engagement* 的方法链：三维交会数据生成 → 机动意图识别 → 意图与交会状态条件化的交互图 → 分布裁剪 → 未来轨迹解码 → 分层监督与滚动预测。

论文预测器属于监督学习。xuance 的 cov 环境用于参考三维状态、动力学推进、障碍判断和环境接口；论文主实验应有独立的单目标、单防御机场景配置。现有 cov 默认是四机追一目标、低速、有限地图和势场逃逸，直接使用其默认参数无法与论文的高速一对一指标比较。项目代码集中在仓库根目录的 `Trajectory Prediction/`，通过独立适配器读取 cov，不修改现有环境的行为。

实现顺序遵循“先建立可评价的数据和基线，再增加论文模块”。论文没有给出完整实现的部分必须在配置和实验记录中标为**复现假设**。

## 2. 方法数据流

```text
三维场景与机动原语
    └─ 同步生成目标/防御机轨迹、交会状态、意图标签
         └─ 按完整轨迹划分数据，再切观测窗与预测窗
              ├─ 意图网络：目标历史 + 防御机状态 → 九类意图概率
              └─ 预测网络：历史 + 交会特征 + 意图概率
                   └─ 交互图 → GAT → 软/硬约束裁剪 → 解码位置增量
                        └─ 积分得到未来三维位置
                             └─ ADE/FDE + 注意力教师损失；在线滚动更新
```

统一使用右手三维惯性坐标系，长度单位 m，时间单位 s，速度单位 m/s，加速度单位 m/s²。原始轨迹保留世界坐标；模型输入可以相对于观测窗末帧平移并用**仅训练集**统计量标准化；评价前恢复到世界坐标。未来真值、未来防御机动作和由其计算出的特征不得进入推理输入。

`Trajectory Prediction` 文件夹名保留用户指定的空格；Python 包采用 `trajectory_prediction`，避免导入路径中的空格。先实现必要文件，目录树表示稳定的模块边界，不要求一次写完所有脚本。

### 当前实现状态

当前实现落在较紧凑的 `src/trajectory_prediction/` 中：`simulator.py` 负责独立的一对一三维场景与标签，`data.py` 负责轨迹级划分和窗口，`intention.py` 是九类 BiLSTM，`metrics.py` 包含 ADE/FDE 与 CV/CA。`prediction.py` 已实现双层时空交互注意力、九种物理候选、可行性/Top-K 裁剪与 GRU 增量解码；`prediction_train.py` 负责冻结意图网络、训练预测器和在独立数据目录上比较模型与 CV/CA；`cli.py` 提供统一命令。配置分为意图实验与轨迹实验两份。`tests/` 检查运动约束、视场采样、时间索引、窗口边界、候选与梯度。

这一阶段的图先对**已观测到的**双方历史状态编码，候选在图上下文之后由九种 6g 速度法向机动生成；硬裁剪目前只检查地面高度，保留直飞回退。论文没有公布候选构造及完整阈值，这些选择均是复现假设。`online.py` 已支持在每个更新时刻用新观测重算意图与 6 s 预测，并保存逐次误差。完整的交会/地形裁剪、能量/风险/时效教师头与损失、cov 适配器仍未实现；目前的模型指标不可称为论文完整方法的复现指标。

## 4. 各模块职责与接口

| 模块 | 输入 → 输出 | 必须保证的行为 |
| --- | --- | --- |
| `sim` | 场景参数、随机种子 → 同步的目标与防御机状态序列 | 论文模式按点质量模型和加速度饱和推进；目标到达逃逸触发距离后，anti-LOS 指令投影到速度法平面；记录原语、触发时刻和 FOV。 |
| `cov_adapter` | cov 环境的一次 `reset/step` → 同一轨迹格式 | 只提供另一种数据来源；记录 cov 的加速度滞后、jerk、低速与多追捕机配置，不把它误标为论文场景。 |
| `data` | 完整轨迹 → 观测窗、未来窗、标签、元数据 | **先按 `track_id` 划分，再切窗口**；同一完整轨迹不得跨训练、验证、测试。保存训练集标准化参数与生成配置。 |
| `intention` | 目标历史 `[B,T,6]`、防御机状态 → `[B,9]` 概率 | 主实验为九类语义机动；训练用交叉熵，保留混淆矩阵和每类准确率。 |
| `graph` | 双方历史、意图概率、交会特征 → 节点/边及隐状态 | 目标和防御机的时间边、同时刻空间边、交会约束边明确分型；边记录距离、距离变化率、LOS 及变化、FOV。 |
| `candidates` | 当前状态、意图概率、运动约束 → 带来源的未来候选 | 每条候选保存使用的机动原语、初始状态和随机种子；候选来自当前可得信息，不从真值轨迹反推。 |
| `cropper` | 候选、图注意力、交会/环境约束 → 有效候选和重归一化权重 | 区分不可行的硬掩码与可学习的软门控；所有候选被遮掉时有明确回退路径；Top-K 只在有效候选中选。 |
| `decoder` | 裁剪后的时空特征 → `[B,T_pred,3]` 增量和位置 | 从观测末帧累加位置；训练可使用预定的 teacher forcing 日程，验证和在线推理不得读取未来增量。 |
| `losses` | 预测、真值、注意力与教师分数 → 分项及总损失 | 几何层计算 ADE/FDE；注意力层按能量、风险、时效三组监督，并记录每项量纲、掩码与权重。 |
| `eval/online` | 检查点、独立场景轨迹 → 指标和滚动预测记录 | 报告单次 6 s 外推及短间隔滚动更新两种结果；每次只使用当时已观测到的状态。 |

建议的统一样本结构：`track_id`、`seed`、`dt`、`target_history[T_obs,6]`、`defender_history[T_obs,6]`、`target_future[T_pred,3]`、`intent_id`、`engagement_history`、`valid_mask` 和场景元数据。历史六维为位置与速度；加速度可以由同步仿真记录或历史差分得到。预测模型输出 `future_xyz`、`intent_prob`、按头组划分的注意力以及候选有效性，便于损失计算与消融。

## 5. 论文实验配置与复现顺序

| 实验 | 论文设定 | 本框架对应步骤 |
| --- | --- | --- |
| 意图识别 | 3D；采样 0.5 s；观测 10 s；约 5 万窗口；按完整轨迹 70/15/15 划分；九类标签；BiLSTM 隐层 128、投影层 64、dropout 0.2；Adam `1e-3`、batch 256、70 epoch | 先完成数据生成、标签、划分和独立意图训练；记录准确率与混淆矩阵。 |
| 轨迹外推 | 采样 0.1 s；观测 8 s（80 步）；预测 6 s（60 步）；约 5 万实例；训练/验证 80/20 | 从同一协议生成监督样本；保留额外的独立场景种子作最终报告，避免仅用验证集报告结果。 |
| 图与训练 | 表示维数 256；空间 6 头、时间 4 头；各 2 层；key/value 维数 64；Top-K 8；温度 0.1；`ω_ADE=0.4`、`ω_FDE=0.6`、`λ_sep=0.1`；AdamW `1e-3`、batch 256、最多 200 epoch | 先训练无裁剪图模型，再加入裁剪与教师分数；统一检查点和配置快照。 |
| 代表性评估 | 目标 300 m/s、防御机 360 m/s；目标最大 9g、防御机最大 15g；目标 FOV 半角 60°；四种转向与爬升/俯冲组合 | 输出三维轨迹、逐时刻误差、ADE/FDE；对比 CV/CA 与论文中的四类网络基线。 |

论文的场景随机化还包括初距 4–8 km、不同 LOS 方位/俯仰、高差、双方初速与过载。配置文件要分别保存**数据集采样范围**和**代表性展示场景**，因为论文两处速度设置不同。

建议按以下里程碑实施，每一步有独立产物：

1. **数据和指标**：仿真轨迹、窗口、九类标签、ADE/FDE、CV/CA 基线。核对单位、窗口长度、轨迹级划分和无未来泄漏。
2. **意图网络**：复现 BiLSTM 训练与测试，冻结一个验证集最优检查点，并输出九类概率。
3. **基础预测器**：历史轨迹 + 意图概率 + 交会特征，先用普通解码器得到可评价的 6 s 轨迹。
4. **图与裁剪**：加入 GAT、三类边、软/硬掩码和候选记录；分别打开每种约束做消融。
5. **教师监督与滚动推理**：加入三组注意力头和损失，报告离线单窗与在线滚动结果，并复现论文的 `+I/+E` 消融。

## 6. 必须显式记录的复现假设

1. **观测图与未来候选的关系**：论文一处定义观测窗内 `2T_obs` 个双方状态节点，另一处称图节点为未来候选。框架将二者明确拆成“历史交互编码图”和“未来候选及其裁剪”，在实验记录中注明这一解释。
2. **解码器**：正文用 MLP 表述增量输出，实验段描述自回归 GRU 与时序记忆交叉注意力。默认实现 GRU 解码并以 MLP 作为每步增量输出头，同时提供简化 MLP 消融。
3. **九类以外的加速度标签**：论文的法向加速度定义是非负模长，但其 11 级实验包含负值。主复现仅使用明确的九类语义标签；11 级结果单列，待确定带符号的轴向定义后再实施。
4. **裁剪条件和符号**：论文集合定义、可行性指示和风险分数的正负方向存在不清楚之处。代码统一约定 `valid=1` 表示可保留、`score` 越大表示越可取，并把距离导数定义为“双方距离增加为正”；逐项记录与原式的对应及修正。
5. **未公布的超参数**：候选生成、边半径、部分阈值、教师分数归一化、软硬裁剪日程和在线更新间隔均配置化，报告所用值、种子和消融，不宣称是论文原始参数。

## 7. 最终验收产物

- 可用固定配置和种子重新生成数据；数据清单包含轨迹数、窗口数、标签分布、场景范围及划分哈希。
- 各模型检查点附配置、代码提交号、训练集标准化统计量、最佳验证指标。
- 评估报告同时给出九类意图混淆矩阵、三维 ADE/FDE、逐时刻误差、可行率、四类基线及意图/交会/裁剪/教师监督消融。
- 论文直接给定的设置与本项目补充的复现假设在报告中分列；cov 场景的结果与论文高速一对一场景分列。
