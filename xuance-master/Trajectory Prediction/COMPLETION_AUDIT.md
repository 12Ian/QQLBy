# 对照论文的补全审计：民用版本 v0.4

基于用户提供的 Yu 等2026年 TAES论文，DOI `10.1109/TAES.2026.3677846`，继续完成已确认的**民用三维预测**范围。下表为v0.3单轨迹补全，末节为v0.4民用交互扩展。不能把本文件解释成原论文场景或数值的完整复现声明。

## 此次发现并补齐的缺口

| 此前缺口 | 此次实现 | 入口/证据 |
|---|---|---|
| 分类和预测共用dropout | 意图分支独立`.2`，预测/基线`.1` | `intention_dropout`；server/paper_forecast/cpu_completion配置 |
| 边仅由隐藏节点表示推导 | 加入7维自身历史位置差、速度差、时间差的边描述 | `history_graph.py`、`model.py` |
| 历史硬掩码和裁剪强度固定 | 历史观测可达性掩码，逐更新增加门控/Top-K强度，保存裁剪状态 | `crop_warmup_epochs`；恢复逐位一致测试 |
| 加权指标早停与论文描述不同 | `both`模式：ADE、FDE均较上次显著改善基准下降才重置耐心计数 | `early_stopping_mode`；权重选模仍独立进行 |
| 比较脚本使用联合训练，只有两个单独消融 | 默认两阶段；每种子共享同一冻结分类器；四格I/T消融与四基线 | `compare --graph-training two_stage` |
| 只评估固定stride窗口 | 实测状态流接口；每一步更新窗口、后验、图与未来预测，严格检查dt | `RollingPredictor`、`rolling-evaluate --refresh-steps 1` |
| 没有论文式图表导出 | 分类CE/准确率、预测曲线、混淆矩阵、ADE/FDE、分时刻误差、灰度检查、复合运动3D图 | `report`；SVG/PDF/300dpi PNG及数组/来源hash |
| 没有分运动类别预测误差 | 分九类的ADE/FDE与恒速基线、窗口和轨迹支持数 | `test_metrics_motion.csv` |
| 只有初始化种子重复，没有独立样本库重复 | 独立数据种子×模型种子的实验矩阵；分层区间与库间SD，支持恢复 | `study`、`bash/run_trajectory_study.sh` |

I为意图条件化，T为三组民用历史教师。`+I+T/-I+T/+I-T/-I-T`只能解释为这两个民用因素的消融，不能将T改称原文专用E。图结构、运动上限投影、优化器、窗口划分在四组之间保持一致；分类预训练成本独立记录。

## 论文未指定的实现选择

渐进裁剪采用线性更新比例；可达性仅检验自身观测的位置/速度变化。时间半径、测量容差、低速速度上限和加速度上限是民用配置。它们的具体取值不来自原论文。

`both`早停使用上次同时显著改善时的两个指标作基准；论文没有唯一指定ADE与FDE的合并规则。低速民用数据采用`.001 m`显著改善阈值，原文为`1 m`，阈值可配置。最优检查点仍按验证`.4 ADE + .6 FDE`选取，二者不是同一个判定。

分类预训练、冻结迁移及预测训练必须具有相同dt、观察长度、类别次序、训练归一化和整轨迹划分。IV-A的`.5 s/20步`和IV-B的`.1 s/80步`由不同配置表达，不能直接互换检查点。新配置保留完整结构256维、6个独立64维图头、2图层、2时间层、4时间头、自回归GRU、Top-K8、温度.1。旧配置/检查点仍可加载。

## 仍不能作为原论文完成项的部分

- v0.4已实现通用双实体历史图和邻居状态FC；原文专用对抗边、视线/可见性等专用描述、特定能量/风险/时效教师，以及原场景仿真和控制闭环仍不属于本次民用实现。
- 没有原作者数据、训练权重和逐实验随机条件，不能验证论文原始表格、88%/94%识别率或其距离误差。民用生成器只用于工程验证，可另外输入真实民用CSV/NPZ。
- 原文每类1000次场景试验尚未实跑；已提供独立民用库重复实验工具，但小规模CPU试跑不能替代原文实验。
- 本机只有CPU。完整结构前向/反向、轻量训练、服务器脚本演练可在此完成；Linux CUDA、AMP、200轮收敛与显存/吞吐须在服务器上实测。

实际新增运行结果见 [VALIDATION.md](VALIDATION.md) 的v0.3记录及 `../outputs/trajectory/completion_validation.json`。服务器运行入口和参数见 [README.md](README.md)。

| v0.3差异 | v0.4实现 | 证据 |
|---|---|---|
| 无外部实体测量分支 | 焦点BiLSTM与邻居末个有效测量FC融合；双方采用共同坐标和训练归一化 | model.py/data.py；旋转一致性与邻居梯度检查 |
| 只有O个自身历史节点 | 2O节点、实体标签、同实体时间边、同期距离半径内跨实体边 | interaction_graph.py；完整结构两样本原生反向 |
| 未处理邻居缺测 | CSV/NPZ可用性mask；缺测归零、图边/记忆/教师排除无效测量 | 无效位置写NaN时预测逐位不变；CSV空值检查 |
| 整轨迹划分不适用于同场景参与者 | 带邻居数据必须显式声明scene_id；整场景分组，恢复拒绝跨区，类别一致性检查；train-only双方归一化 | 25/5/6场景，50/10/12轨迹；泄漏检查 |
| 只有独立运动点生成器 | 六类固定路线民用通行规则：交叉、共用通道、合流、坡道、优先级变化、分离对照 | simulate；真实36场景/72轨迹，保存间距与等待诊断 |
| 双方观察图教师差分可能跨实体 | 时间索引分实体重置；差分不跨边界，缺测加速度和无效查询行排除 | objective.py；真实反向与缺测检查 |
| 不能单独检验外部历史贡献 | I/C四格消融；C关闭时邻居FC为零、图仅O焦点节点，输出不依赖邻居值 | 8方法×2初始化种子的16次原生训练 |
| 单状态滚动流 | 同期双方状态和mask滚动更新；与一次性历史推理逐位一致 | 588个实跑滚动窗口、7,056行未来预测 |
| 同场景两轨迹统计不独立 | 整场景bootstrap、分场景类型/观察近邻子集误差；独立场景库×初始化重复 | metrics.py/study.py；两独立库×两模型种子×两方法 |
| 服务器只有单轨迹流程 | 民用交互配置、paired_scene原生入口、新Bash实验矩阵、v0.4源码包 | Git Bash/CPU完整八方法演练与解包原生反向检查 |

C表示民用邻居历史，T仍是民用历史教师；二者均不能改称论文专用E。静态FC、全局时间记忆和cross-attention可以读取全部有效邻居，距离半径只限制GAT跨实体边。路线、通行优先级、场景类型和未来状态不作为网络输入。

本次仿真是预测代码的工程样本，九类方向标签不等于通行策略分类。主实验6个测试场景只覆盖合流/优先级变化/共用通道，观察段多数标签均为直行；因此分类100%不构成九类识别能力证据。另已实际生成60场景的独立覆盖库，在训练前按类别元数据确定划分，9个测试场景覆盖全部六类，完成234窗口评估及六面板图；两类窗口标签为直行/上行，九类平衡识别实验仍未实跑。预测短训未优于匀速基线的全部指标，不能宣称达到论文性能。
