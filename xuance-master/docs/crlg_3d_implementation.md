# CRL-G 三维低速 MADDPG 方法迁移

本实现位于 `xuance/environment/multi_agent_env/crlg_3d/`，与旧城市围捕环境分离。
它复用论文的共同遭遇平面、概率目标终点、可达区并集覆盖和中末段制导结构，
但物理尺度为 1 km、约 8–11 m/s 初速，训练算法为 MADDPG。因此不把训练数值与论文
高速拦截器 IPPO 结果直接比较。

## 物理与任务

- 每机状态为三维位置、速度、实际加速度及独立偏航角，共 10 维。每个物理步按
  `p'=p+v*dt+0.5*a*dt²`、`v'=v+a*dt`、`a'=a+sat_j((a_cmd-a)/tau)*dt`
  和 `yaw'=wrap(yaw+omega*dt)` 离散更新；加速度滞后常数 0.5 s。
  追击机和目标都限制实际加速度、jerk 和偏航角速度。偏航由独立规则控制：
  追击机朝向当前目标，目标朝向水平速度；偏航不改变平动轨迹。
- 追击机和目标均只设 11 m/s 速度上限，允许减速至悬停。每回合共同抽取追击机
  初速 7.6–8.4 m/s，目标初速固定为其 1.25 倍，即 9.5–10.5 m/s。
  当前初始交战距离约 400 m；以论文约 90 km、2000/2500 m/s 为参考，
  保持目标/追击机速度比并给速度上限留出机动余量。这个选值的名义相向交会
  时间约为 21–23 s，而论文对应约 20 s。
- 中段最大指令 0.11 m/s²，末段 PNG 0.22 m/s²，目标最大侧向加速度
  0.07 m/s²；它们是按距离及名义交会时间缩放后的工程近似，不是论文原值。
  默认中段/末段/目标 jerk 上限分别为 0.22/0.44/0.14 m/s³，偏航角速度
  上限为 π/4 rad/s；这些默认值按加速度上限和 0.5 s 滞后选取，尚需实机校准。
- 每回合有 3–6 架有效机，六个 agent key 固定；初始队形同侧集中，
  横向位置按实际有效机数量居中。
- 无建筑；水平范围 0–1000 m，高度 50–350 m。任何有效机或目标触边时回合无效，
  训练时另给边界惩罚，评估时单列无效回合。
- 目标 CV、CA、Singer 三种真值模式独立抽样，不根据追击机动作反应。
  三种模式生成目标的期望加速度，实际加速度经同一滞后及 jerk 约束跟踪；
  CA/Singer 指令限制在初始 LOS 的法向平面，轴向速度仍由初值决定。
- 中段每个决策步按各机当前距离/闭合速度估计 `t_go`，取中位数作为公共估计，
  更新 `t_e=t+t_go`。当闭合速度非正时使用很小的正下限，并将估计截在
  70 个决策步（35 s）的最大回合时长内。首次进入剩余 5 s 时锁定该次
  `t_e`，避免末段截止时刻随机动反复后移。论文采用逐步几何估计，
  公共时刻的中位数、末段锁定及最大步数是本方法迁移的实现约定。

## 预测、可达区和奖励

- 目标观测为当前状态；训练使用无噪声的位置/速度，评估加入位置/速度测量噪声。
  加速度由相邻测量速度差估计，并限制在初始 LOS 法向平面。评估末段 PNG
  使用该测量状态，而非目标真值。
  使用 CV/CA/Singer 状态转移与机动噪声协方差传播得到
  `N(q_hat(t_e), Q(t_e))`，不使用未来真值。
  Singer 预测将期望加速度的 OU 过程和实际加速度的滞后作为联合线性状态传播；
  jerk 和速度饱和仍是预测高斯模型的近似误差来源。
  Singer 预测过程噪声由真值 OU 加速度噪声参数换算；CV/CA 使用单独的
  `process_sigma`。位置、速度和加速度预测噪声也按新尺度调整；这些值仍需
  用正式训练的误差校准。预测误差奖励当前默认 `k=0`，未使用论文未披露的未来误差窗口。
- 固定遭遇平面由初始队形质心和目标 LOS 构造。追击机零指令终端点用同一
  动力学积分得到。剩余时间大于 5 s 时，二维可达半径由全侧向指令的动力学
  查表与插值得到；最后 5 s，从当前加速度状态沿 12 个方向积分，形成可达
  端点多边形，触边路径不计入。云样本对应的三维端点还需落在地图内。
  这仍是近似可达区：远时域采用对称圆，近时域只采样固定方向的持续指令。
- 固定标准正态样本投影到目标二维云，统计样本落入任一有效机近似可达区的比例。
- 过程奖励为 `0.6*coverage - 0.3*(projected_miss/30m)^2 - 0.1*(|a_cmd|/a_limit)^2`。
  能耗项用当前制导阶段的加速度上限归一化，使物理尺度变化时权重含义保持稳定。
  终端奖励为个体/团队最小真实三维脱靶距离的倒数平方混合，偏置 5 m、权重各半，
  再乘 1000。以上数值是项目默认值，论文未披露其数值，可在 YAML 中修改。
- actor 输入为固定 19 维：剩余时间、自己二维预测终点误差、按距离排序的
  五个队友相对二维误差、五个有效性掩码和自己有效性掩码。两个 attention 流分别
  汇总近两机与远三机，actor 输出两个遭遇平面法向加速度分量。
- MADDPG critic 接收六机观测与动作，并屏蔽无效机 token 和动作。高斯探索后
  的动作及 critic 使用的动作均投影到单位圆盘；无效机动作归零。

## 训练和评估

```bash
python examples/crlg_train.py --device cuda:0 --steps 3000000 --run-name baseline
python examples/crlg_evaluate.py --device cuda:0 --model /absolute/checkpoint.pth --episodes 100
python examples/crlg_evaluate.py --device cuda:0 --model /absolute/checkpoint.pth --episodes 100 --noise-scale 0 --team-size 4 --target-mode Singer
python examples/crlg_smoke.py
```

训练策略控制至锁定的 `t_e`，评估中最后约 5 秒切换 PNG；回合最多 70 步。
JSON 报告初始与最终估计交会时刻、实际步数、结束原因、最终三维脱靶
距离、最近接距离、触边无效原因及 1/2/5/10 m 阈值成功率。旧 15 m 捕获事件
不参与新任务定义。结果按队伍规模和目标模式分层，并记录覆盖饱和率及校准圆与
论文理想圆的面积比；`--noise-scale 0` 提供无测量噪声对照。JSON 还记录随机
种子、模型与关键代码哈希、奖励分项、指令能量；`--save-trajectories` 可存逐步轨迹。

- CV/CA/Singer 各跑完一个环境回合，末段 PNG 均为 10 个 0.5 s 决策步；
  CA/Singer 加速度在初始 LOS 轴向的投影为零。
- 在目标和追击机分别触边的构造场景中，均得到对应无效原因、回合终止和
  边界惩罚。评估 JSON 的奖励分项之和与累计回报一致。
- `crlg_train.py --steps 32 --parallels 1` 完成一次 CUDA 训练烟雾运行并保存
  checkpoint；该 checkpoint 的两回合含噪评估和一回合无噪 Singer 轨迹导出
  均完成。烟雾运行不能用于报告训练性能或与论文比较。
- `--steps 80 --parallels 1` 完成一次覆盖完整回合的短训练；从 TensorBoard
  event 文件中读到了 `Train-SubRewards-agent_0/coverage/rank_0` 标量。

上述检查针对映射前参数，不能当作新速度参数下的性能结果。目前仍需正式训练
和足够样本的评估，才能判断成功率、有效回合比例及各奖励
权重是否合适。远时域可达圆没有计入当前执行器状态和完整轨迹触边约束；近时域
多边形也不是连续控制下的严格可达集。

## 速度映射后的执行检查

- 从当前 YAML 创建环境后，CV、CA、Singer 各完成一个 3 机回合；初始目标与
  追击机速度比均为 1.25，当时固定交会时间均为 22 s，末段均有 10 个 PNG 步，
  奖励有限且无触边无效回合。这是执行检查，不代表策略性能。
- `examples/crlg_smoke.py` 在 CUDA 上再次完成动作投影和 MADDPG 更新。
- `crlg_train.py --steps 32 --parallels 1 --run-name speed_map_smoke` 完成
  一次新参数下的 CUDA 训练入口烟雾运行；这不是正式训练。
- 零动作回合中，队形居中后 3 机 CV/CA/Singer 的初始覆盖率均为 1，
  回合平均覆盖率约为 0.22–0.28；6 机平均约为 0.43–0.75。
  这些值只用于检查覆盖率计算没有长期卡在同一个值。
- 同一随机种子的 3 机 CA 场景中，简单朝预测误差反向转向的动作使回合平均
  覆盖率由零动作的 0.181 提高到 0.764；说明覆盖奖励对控制动作有响应，
  不代表学习后策略的效果。
- 新参数下的短训练 checkpoint 已完成一回合含噪 CA 评估，JSON 正确记录
  7.896/9.871 m/s 的初速及 1.25 比例；该回合脱靶 11.69 m，不能据此评估
  正式训练的成功率。
- 映射前保存的 checkpoint 与新参数分布不一致，正式评估须重新训练模型。
