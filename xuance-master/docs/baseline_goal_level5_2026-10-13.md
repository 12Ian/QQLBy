# 第五级安全捕获实验

## 验收目标

实际训练课程进入 level=4，并在原最终任务上达到安全捕获率至少 80%、整回合碰撞率不超过 10%。还需用新的评估种子复核。到达课程等级、日志有限或训练成功次数增加均不能单独作为完成依据。

最终任务保持：1000×1000 m 地图、高度 50–350 m、100 栋固定建筑、4 架追捕机最高速度 11 m/s、逃逸机巡航/受威胁速度 3/9 m/s、捕获半径 15 m、同一追捕机保持 2 s 或 5 m 直接拦截、最多 400 个决策步。建筑文件与 001/002 相同。

## 实验 003

冻结配置：`experiments/baseline_exp003.yaml`。预设 1500000 个环境转移，每 50000 步用 100 回合评估。沿用 002 的 `best_stage_0.pth` 初始化 actor 和 target actor；critic 与优化器重新初始化。使用相同的 512×512 MLP，actor 初始学习率 0.00005、critic 0.0003、batch 512。

该实验同时修改奖励、探索和前四级课程，是一次新 baseline 版本验证，不用于声称某一个参数单独产生了收益。每次运行保留配置、代码快照、源文件 hash、初始化 checkpoint hash 和进程退出记录。

### 奖励

```
r_i = 0.1 × [
    300 × capture_success_without_training_failure
    - (d_i / 1000) × elapsed
    - 3 × q(building_clearance, 50) × elapsed
    - 3 × q(boundary_clearance, 50) × elapsed
    - q(teammate_clearance, 10) × elapsed
    + contact_penalties
    + gamma × Phi(next_state) - Phi(previous_state)
    - 300 × training_collision_failure
]
Phi(state) = -target_distance / 10
q(c, L) = max(0, 1 - c / L)^2
```

真实捕获或失败终止时，下一状态的势函数取 0；时间截断保留非终止状态势函数，并继续使用 bootstrap。测试检查不同长度、不同距离路径通向捕获时，塑形项的折扣总和相同。

距离塑形参考 [Ng、Harada、Russell 的势函数奖励塑形论文](https://people.eecs.berkeley.edu/~pabbeel/cs287-fa09/readings/NgHaradaRussell-shaping-ICML1999.pdf)。其理论结果不保证使用函数逼近的实际网络会收敛；本轮同时改变的安全代价与课程另行以任务评估检验。

训练中任意追捕机首次碰撞结束该回合，全队承担失败惩罚；评估关闭碰撞终止，沿用原来的完整回合规则。安全成功率仍要求整回合所有追捕机均没有任何碰撞。奖励整体缩放 0.1，缩小 TD 目标的数值幅度；日志记录缩放后的实际奖励。

## 实验 005：MATD3

冻结配置：`experiments/baseline_exp005.yaml`。改用两个独立 Critic，目标值取两者较小值；目标动作加入标准差 0.2、截断到 ±0.5 的噪声，再截断到动作空间。Actor 每两次 Critic 更新一次，并使用第一个 Critic 的策略梯度；目标网络在 Actor 更新时软更新。沿用 tau=0.001。

```
a_next = clip(mu_target(s_next) + clip(N(0, 0.2²), -0.5, 0.5), action_low, action_high)
y_i = r_i + gamma * (1 - terminated_i) * min(Q1_target(s_next, a_next), Q2_target(s_next, a_next))
L_critic = mean((Q1-y)² + (Q2-y)²)
L_actor = -mean(Q1(s, mu(s)))
```

双 Critic、动作平滑与延迟更新参考 [Fujimoto 等的 TD3 论文](https://arxiv.org/abs/1802.09477)及[作者实现](https://github.com/sfujim/TD3/blob/master/TD3.py)。本仓库使用联合观测/动作的多智能体 Critic，因此此次实验记为 MATD3。算法调整能否改善本任务必须以实际评估证明。

与 004 保持相同的奖励、五级课程、最终物理任务、建筑文件、网络宽度、学习率、探索噪声、初始化 Actor、随机种子及 1500000 步预算；Critic 和优化器重新初始化。005 同时引入上述几项算法调整，不能用其结果归因于某一个参数。

修复了仓库原 MATD3 策略初始化缺少 Actor 辅助模块标志的问题，并补充原实现中缺失的目标动作平滑。兼容默认配置；005 显式启用 Q1 Actor 目标。新增行为测试检查目标动作边界、噪声截断、独立 Critic、较小目标 Q、真实延迟参数更新和 Q1 Actor 目标。

## 实验 006：从第三级模型继续学习制动避障

冻结配置为 `experiments/baseline_exp006.yaml`，预算增加到 3000000 个新环境转移。从 005 的 `best_stage_2.pth` 加载完整 Actor、双 Critic 和对应目标网络，共 36 个参数张量。优化器及回放池重新创建；这不是恢复全部运行状态。前两级资格由 005 的实际评估和升级记录证明，006 从 level=2 继续，后续仍需满足原来的两次评估门槛才能进入第四、第五级。

006 仅在避障代价中将静态间隙替换为考虑速度的有效间隙：

```
v_closing = max(velocity projected toward a wall/building, 0)
d_brake = 1.5 * v_closing + v_closing² / (2 * max_accel)
c_effective = max(0, clearance - d_brake)
r_obstacle = -0.1 * 5 * q(c_effective_building, 50) * elapsed
r_boundary = -0.1 * 5 * q(c_effective_boundary, 50) * elapsed
```

1.5 s 包含一个决策周期及加速度响应时间。建筑使用到长方体最近点的接近速度，边界分别计算六个方向后取最小有效间隙。这是奖励风险指标，使用理想制动近似；没有改写动作、限制最高速度或阻止实际碰撞。距离塑形、稀疏成功奖励、失败惩罚与其余奖励分项继续沿用 005。旧配置默认关闭该指标。

## 实验 007：制动距离越线后继续增加代价

64 回合诊断发现：5 次地标楼碰撞前的间隙均不足估算制动距离，006 在这些状态的有效间隙截为 0，使建筑代价进入饱和区。新增配置 `baseline_braking_deficit_penalty: true` 允许风险指标保留负有效间隙：

```
c_effective = clearance - (1.5*v_closing + v_closing²/(2*max_accel))
r_obstacle = -0.1 * 5 * max(0, 1 - c_effective/50)² * elapsed
r_boundary = -0.1 * 5 * max(0, 1 - c_effective/50)² * elapsed
```

因此已进入制动距离内时，越线越多，代价继续增长。负的是“扣除反应/制动距离后的风险指标”，不是允许穿入建筑；物理运动、碰撞判据和动作执行均未修改。配置默认 false，006 仍沿用其原奖励。开启此项须同时开启制动安全指标。
