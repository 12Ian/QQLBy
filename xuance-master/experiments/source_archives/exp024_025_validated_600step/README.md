# 600 步回合上限与评估调度：实施及验证

最终采用用户最后确认的 **600 决策步＝300 秒**，训练和所有评估统一使用。300 步/150 秒的临时配置已替换，未在服务器执行该临时配置。

| 项目 | 本版本配置 |
|---|---|
| 单局上限 | 600 步，决策间隔 0.5 秒，即 300 秒 |
| 当前级别评估 | 每 200000 训练环境步，100 局 |
| 已通过级别回归 | 每 1000000 训练环境步，每级 100 局 |
| 额外第五级评估 | 每 1000000 训练环境步，100 局；当前已是第五级时复用本级评估 |
| 初始、结束评估 | 保留初始评估、结束检查和五级各 100 局终评；独立固定场景验收脚本保留 |
| latest 检查点、计时汇总 | 每 50000 训练环境步 |
| 晋级门槛 | 本级至少 100000 步，连续两次安全成功率 ≥80%、碰撞率 ≤10%，保持不变 |
| 正式预算 | 每方法 6000000 训练环境步，16 并行，种子 1 |
| 评估并行及安全实现 | 16 并行，已验证的 Numba 后端；8 秒安全预测时域及每物理子步检查保持不变 |
| 碰撞口径 | 不计机间碰撞；建筑/边界碰撞终止，保持不变 |

晋级检查间隔变为 20 万步后，理想情况下进入某级后的第 20 万、40 万步连续通过才升级。600 万步的本级评估有 31 组（包含第 0 步）；latest 保存有 120 次。旧级别回归只诊断遗忘，不更新网络、不额外限制晋级。

## 验证结果

最终 600 步版本本地关键测试 **16 通过**；服务器相关测试 **82 通过**，覆盖课程调度、训练入口、MATD3、检查点流程及安全过滤逐位对照。

- 原生环境在第 599 步不超时，第 600 步按 `truncated` 超时结束；不误记为碰撞，累计时间为 300 秒。
- 对实际训练主循环进行确定性 600 万步调度测试：本级每 20 万步、旧级别每 100 万步、第五级按期测量并在当前第五级时复用、每 5 万步保存、结束五级各 100 局均符合约定。
- 旧版配置的评估、保存行为测试继续通过。

服务器另外执行两种方法各一次真实短程集成测试。测试保留 **600 步回合上限、16 个训练环境、16 个评估环境、Numba 和五级终评**；仅将预算缩小为 128 训练环境步、网络缩小、每组评估改为 16 局，并按比例缩短评估/保存间隔，以验证实际执行。

| 方法 | 训练环境步 | Critic/Actor 更新 | latest 保存 | 本级评估节点 | 五级终评 |
|---|---:|---:|---:|---|---|
| MATD3 | 128 | 6 / 3 | 8 | 0、64、128 | 各 16 局 |
| MATD3-HGAT | 128 | 6 / 3 | 8 | 0、64、128 | 各 16 局 |

两者均生成最终检查点，网络分支发生更新、参数有限，优化器更新次数符合预期。集成过程分别耗时约 97.73 秒、102.07 秒，包含大量短预算下的评估及编译启动成本，不能外推完整训练速度，也不代表训练后的围捕效果。
