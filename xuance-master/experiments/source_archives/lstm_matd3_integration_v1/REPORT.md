# LSTM 已接入标准 MATD3：修改与验证报告

全部代码修改和测试在服务器完成。分支：feat-coverage-reaward；基线提交：4ac54745a14dc1010a438ae8bd2033dbdf56b8dd。

## 实现

- 冻结第4轮 LSTM，按 0.5 秒步长维护每环境独立的11帧原始历史；输入仍为9×71。
- 为每机加入未来1/2/3秒的目标位移（除以100），观测79→88维；共享Actor含ID输入83→92维，集中Critic输入332→368维。
- 原始建筑30维仍位于观测末尾；不增加预测有效标志。前5秒使用匀速外推。
- 在线推理只消费历史与当前合法信息，不读取未来标签；在向量环境主进程批量运行。
- 终止观测与自动reset观测分别使用旧、新回合历史；replay存储已增强的obs和obs_next。
- Actor、目标Actor、双Critic及目标双Critic共六个首层显式映射旧输入列，新增列置零；不改变TD3更新公式。
- 三份模式配置：none/cv/lstm。三组均从同一标准MATD3检查点初始化，使用新的优化器与空replay。
