# MATD3 + LSTM 长程捕获率对照

执行顺序：LSTM seed 1、2、3，然后匀速预测 seed 1、2、3。原版不再训练，只评估已有检查点。

每个任务从相同原版完整策略权重开始，新增预测输入的权重初始化为零；优化器和 replay 重新开始。每次继续训练 600 万环境步、16 个并行环境，固定第 5 级、每回合最多 600 步，物理步长 0.5 秒。共 3600 万新训练步。LSTM 预测器冻结，不参与策略梯度更新。

LSTM 与匀速版使用同样的 9 维预测输入位置、网络规模和训练预算。两者的差值用于判断学习预测相对匀速预测的收益。与原版的差值同时包含额外训练的影响；原版只有一个已训练检查点，不伪装为三个训练种子。

验证：每 20 万环境步，在第 5 级 100 个固定场景上验证，按安全捕获率、碰撞率、回报依次选择最佳检查点。每 5 万步保存最新权重。训练种子和场景种子分离，模型构建后重新固定学习器随机数状态。

独立测试：每个任务训练结束后，最佳检查点测试五级各 200 场景，最终检查点另测第 5 级 200 场景。原版已有检查点最后在同样的五级场景上测试。每回合显式设置场景种子并核对初始状态摘要，避免按回合完成顺序选样本。测试标签不参与模型选择。城市地图仍是原有五张固定地图。

目录说明：
- protocol.json：固定协议与执行顺序。
- status.json、coordinator.log：总队列状态与日志。
- jobs/<方法>_seed_<种子>/job_status.json、process.log：任务状态与日志。
- jobs/.../results/curriculum_eval.csv：验证曲线。
- jobs/.../results/best_model/：验证集选定模型。
- jobs/.../test/：独立测试逐场数据及指标。
- baseline_reference/：原版已有检查点的独立测试。
- capture_summary.json、RESULTS.md：全部完成后自动生成的对照报告。
- final_check_report.json、preflight_report.json：启动前核验记录。
- frozen_source_sha256.json、frozen_inputs_sha256.json：源代码、配置及输入模型指纹。

训练在服务器的独立进程中顺序运行，任一任务失败即停止后续队列并写明错误。当前尚无长程效果结论，报告会保留正负差值。
